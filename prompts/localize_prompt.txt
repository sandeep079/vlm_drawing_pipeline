region type isn't present. Do not confuse a section view with an orthographic

Return ONLY a JSON array, no markdown fences, no extra text, in exactly this
schema:

[
  {"label": "<one of the 5 types above>", "box_2d": [x0, y0, x1, y1], "conf": <float 0.0-1.0>},

]

relative to the full image width and height (NOT pixel coordinates, NOT 0-1).
